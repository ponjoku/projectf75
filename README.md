# PLEASE READ INSTRUCTIONS

Automated report comparing outcomes for children with severe acute malnutrition who received
modified F75 vs. standard F75 therapeutic milk (interim data, first 6 months of a year-long trial).

**Team:** Peace, Pavithra, Hasna, Aigerim


## To run the code

1. Install the packages
install.packages(c("here", "readr", "dplyr", "stringr", "forcats", "config", "labelled", "gtsummary", "corrplot", "tidyverse"))

2. Run make in the terminal
This cleans the data, runs each script and builds an html report.
Alternatively, knit the Report.Rmd file in project directory

3. To delete all outputs and start fresh, type "make clean" in the terminal.
